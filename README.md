# Sakura Lively Widgets
Material-style widget wallpaper for Lively (clock, world times, weather, CPU/RAM/battery, now playing).

## Setup
1. Install Lively Wallpaper.
2. Add your own image named wallpaper.png in the same folder as index.html.
3. Zip index.html, LivelyInfo.json and wallpaper.png, then drag the zip into Lively.

## Customize
Change the city by editing latitude and longitude in index.html.
